## 3. Finding: plural secret keywords were accepted (fixed in the gateway and Glass)

- **What:** the secret refusal (`INLINE_SECRET`, `desktop_runtime/v5_contract.py`) matched `password:` but not
  `passwords:`, `credentials =`, `tokens:`, `secrets =`, `api_keys:` or `cookies:`. The keyword was followed by an
  `s`, so the `\s*[:=]` part never matched.
- **How it was found:** the new corpus test. It failed on `credentials = example-only` at every one of its 13 entry
  points.
- **Fix:** an optional plural (`s?`) in the gateway rule, which 8 modules share, and in the two Glass copies that warn
  while typing (`services/secretGuards.ts`, `services/command.ts`). Six plural entries were added to the corpus, and a
  Glass test was added. The full gateway suite still passes, so no existing text depended on the gap.
- **Still open:** the same rule is copied on the phone and was not changed in this run:
  - `gateway/GatewayV5CommandAdapter.kt`
  - `gateway/GatewayV5AskAdapter.kt`
  - `gateway/FleetAlerts.kt`
  - `gateway/GatewayV5LabAdapter.kt`
  - `connector/ConnectorRules.kt`
  - `mind/lab/MindLab.kt`
  
  The retired `apps/pc-companion` copy was not changed either. The phone fix needs a Gradle run and its own release.
  Texts sent to the phone from the Command Center are refused at the gateway first, so this run already covers that
  path.

## 6. Risks accepted

- **Startup refusal.** A file from a newer Cyclone stops the PC runtime at start (S0-3). That only happens after a
  downgrade, which Cyclone does not support. The message says what to do.
- **Pre-migration copies are not encrypted.** They have the same protection as `command.db` itself. Stage 12 brings
  encrypted backups.
- **Wider refusal.** The plural rule now also refuses ordinary texts such as "Tokens: 3 per day". A secret-free
  rewording ("3 tokens a day") is accepted.
