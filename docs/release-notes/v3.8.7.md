# Cyclone 3.8.7

Cyclone 3.8.7 turns the standalone Mobile AI path into a persistent, evidence-driven Android task runtime instead of a shallow page-decision loop.

## What changed

- The overlay now runs one persistent local task session with checkpointed state, bounded convergence and resumable human/GATE suspension.
- Standalone Mobile AI consumes the same Android-native Page Card contract used by Cyclone PC: fresh observation-scoped element IDs, semantic search, inspection, rich page evidence and typed failures.
- Android action acceptance is no longer treated as task success. Every mutation uses a fresh authoritative after-observation and semantic verification before learning or completion.
- Verified PC/App Graph/Brain routes are reused locally through the same canonical PhoneToolExecutor boundary; the old weak direct Brain replay shortcut is removed.
- Recovery now progresses through structured page evidence, goal-ranked semantic search, supplemental inspection, bounded exploration, silent screenshot vision and replan/backtrack before non-convergence.
- Model `blocked` and malformed responses are recoverable unless deterministic Android evidence proves a real hard blocker.
- Convergence is based on semantic evidence rather than rotating observation UUIDs, so retries remain bounded without false progress.
- Completion checks target the final requested state and require fresh page evidence rather than accepting a successful click as completion.
- Consequential GATE actions now resume with an exact, short-lived, one-shot approval for the blocked action. Credential, password, PIN, OTP and verification-code entry remains human-only.
- Production wiring tests now enforce that the live overlay uses the persistent runtime, PC-parity contract and semantic verification path.
