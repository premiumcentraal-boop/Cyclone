# Cyclone 3.5.2-beta

Cyclone 3.5.2-beta keeps the full 3.5.1 Cyclone experience intact and adds a lightweight Settings link to a separate Teamwork Sniper companion.

## Cyclone Mobile

- Preserves Home, Teach, AI, Routines / Automations, Brain, Settings, PC Gateway and existing runtime/services.
- Package remains `com.cyclone.mobile`.
- Version is `3.5.2-beta`, versionCode `38`.
- Teamwork Sniper configuration is intentionally not duplicated inside Cyclone.

## Teamwork Sniper companion

Expected standalone package: `com.cyclone.teamworksniper`.

The companion targets Picnic Teamwork (`tech.picnic.workapp`), uses notification triggers and semantic Android Accessibility reading, requires Notification Access + Accessibility permission, and must be explicitly armed before claiming. Shift discovery/claim execution must remain screenshot-free and OCR-free, and it must never claim a non-matching shift.

The final release must not be described as physically verified until both APKs are installed and accepted on the target Pixel 8 and live Teamwork evidence is recorded.
