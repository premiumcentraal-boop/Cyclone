# Cyclone 3.6.0-beta.1

Install hotfix on top of 3.6.0-beta. Physical Pixel 8 is still **UNVERIFIED**.

## Downloads
- **Cyclone Mobile 3.6.0-beta.1** — Android APK (`versionCode` 41, package `com.cyclone.mobile`)
- **Teamwork Sniper 3.5.3.3** — separate Picnic Teamwork APK
- **Cyclone PC Companion 3.6.0-beta.1** — Windows installer that stops running sidecars before overwrite

## Why the previous beta failed to install
- **Phone “App not installed”:** `com.cyclone.mobile` was already on the Pixel, signed with a *different* CI debug key. Android refuses the upgrade and only shows “App not installed”.
- **PC “Error opening file for writing … CycloneAgentMCP.exe”:** the old Companion was still running, so NSIS could not replace the sidecar.

## Fixes in this build
- NSIS pre-install / pre-uninstall hooks force-stop `Cyclone PC Companion.exe`, `CycloneAgentMCP.exe`, and `CyclonePCRuntime.exe` before copying files.
- Android debug builds now use a repo-pinned debug keystore so later 3.6 betas can update in place.

## Install this build
1. **Windows:** you can run the new installer over the old one. If a leftover dialog still appears, click Abort, close Cyclone PC Companion from the tray, then rerun the installer.
2. **Pixel:** uninstall the existing **Cyclone** app first (Settings → Apps → Cyclone → Uninstall). Then install `Cyclone-3.6.0-beta.1.apk`. This one-time uninstall is required because the previous APK used a different signing key. It deletes local Cyclone app data.

## What this is not
- Not 4.0.0 and not a stable `main` release.
- Pixel slices 1–4 remain **UNVERIFIED**.
- The Windows installer is still unsigned.
