# Cyclone 3.5.3

Cyclone 3.5.3 aligns Mobile, PC Companion, Device Gateway and MCP components and introduces Teamwork Sniper as a separate lightweight APK.

## Highlights

- Teamwork Sniper runs directly on Android with no PC requirement.
- Notification-triggered, screenshot-free Teamwork reading through Accessibility.
- Local semantic UI mapping can navigate toward the shift surface without coordinate scripts.
- Exact, combination and same-day sequence rules for M1, M2, S1, S2 and S3.
- Explicit Enabled + Armed gate before any claim.
- Fresh semantic re-check and post-action verification for every claim.
- Optional OpenRouter connection with encrypted API key and configurable model.
- OpenRouter is advisory only; deterministic rules remain the action authority and automatic fallback.
- Cyclone Mobile keeps its existing Home, Teach, AI, Routines, Brain, Settings and PC Gateway product surfaces.
- PC Companion, Device Gateway and both MCP packages are aligned to 3.5.3.

The release remains unpublished until CI and the required physical Pixel/Teamwork acceptance are complete.
