# Cyclone 3.6.0-beta

GitHub **pre-release** for V4 phone autonomy. Physical Pixel 8 is still **UNVERIFIED**.

## Downloads
CI attaches these after Combined Release CI finishes:
- **Cyclone Mobile 3.6.0-beta** — Android APK (`versionCode` 40)
- **Teamwork Sniper 3.5.3.3** — separate Picnic Teamwork APK if the mobile job produces it
- **Cyclone PC Companion 3.6.0-beta** — Windows installer with Device Gateway + Agent MCP
- Checksums and source SHA land next to the installers

## What this beta adds
- **Page card compact** — `phone_observe` / `phone_locate` keep `pageText` and `pageSummary`. Controls are goal-ranked.
- **Act envelope** — `phone_act` returns `ok`, `pageChanged`, `before`, `after.pageCard`, `delta`, `errorClass`, `generation`. HTTP 200 is not success.
- **Stale protection** — reused `elementId` / generation mismatch returns `STALE_ELEMENT` and does not tap.
- **Coordinate taps** require `visionFallback=true`.
- **Skill compile** — verified steps become a *disabled draft* in the existing AutomationStore. Secrets stripped.
- **Agent OS** — per-device fleet health planes, PC Companion recovery UI, verified-route evidence only.

## What this is not
- Not 4.0.0 and not a stable `main` release.
- Overlay Analysis → Confirm → Working → Live → Gate is specified, not the shipped UI.
- `phone_skill_save` / `phone_skill_run` are not wired yet.
- Pixel slices 1–4 remain **UNVERIFIED**.

## Install notes
The Android APK is CI debug-signed and the Windows installer is unsigned. A differently signed prior Android build may need to be removed first, which removes that app's local data.
