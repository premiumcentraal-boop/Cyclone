# Cyclone 3.6.0-beta

Integration candidate for V4 phone autonomy. **Not a physical Pixel release.**

## What landed

- **Page card compact** (`phone_observe` / `phone_locate`): `pageText` and `pageSummary` always survive. Controls are goal-ranked. Window + `nextCursor`, not "exactly 12 controls".
- **Act envelope** (`phone_act` / gateway action): `ok`, `pageChanged`, `before`, `after.pageCard`, `delta`, `errorClass`, `generation`. HTTP 200 is not success.
- **Stale protection**: reused `elementId` / generation mismatch returns `STALE_ELEMENT` and does not tap.
- **Coordinate taps** require `visionFallback=true`.
- **Skill compile**: `SkillCompiler.compile(verifiedSteps)` writes a *disabled draft* into the existing `AutomationStore`. Secrets stripped. No second brain.
- **Agent OS hardening**: per-device fleet health planes, PC Companion recovery UI, verified route evidence only, Mobilerun CI submodule init.
- **V4 docs**: build bible, directions, roadmap, overlay handoff, MCP `SKILL.md`.

## What this is not

- Not 4.0.0.
- Overlay Analysis → Confirm → Working → Live → Gate is specified, not the shipped UI in this beta.
- `phone_skill_save` / `phone_skill_run` are not wired yet.
- Physical Pixel 8 acceptance is **UNVERIFIED**.
