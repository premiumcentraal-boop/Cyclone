# Cyclone 3.2.0-beta.1 — Massive Update

## What this release is

The V3.2 update is the first release where the phone autonomy loop is complete end
to end: Android access is transparent and user-owned, the AI operates inside an
explicit control tier, and the PC + Codex gateway can actually see and browse the
phone instead of just sending commands.

## Android: permission center + AI control tiers

- Every Android capability Cyclone uses now maps to a visible setup row
  (phone control, enhanced control, notifications, calendar, overlay, battery,
  exact timing, keyboard) instead of being silently inherited from the embedded
  runtime.
- Three AI control tiers are enforced on the phone and in the PC/Codex gateway:
  Guided, Balanced and Full control. Choosing a tier never grants Android access,
  and Android grants never become blanket AI consent.
- Payment, credentials, destructive changes, security settings and final sends
  still require local confirmation in every tier.
- SMS, contacts, all-files access and silent package-install permissions were
  removed from the embedded runtime surface.

## Page context and live screen

- Android page observation is expanded so agents receive complete page context:
  semantic controls, page title and screenshot evidence.
- The PC live stream pipeline is repaired so the Companion shows the phone
  screen in real time instead of sitting on "Reconnecting".
- The stream recovers automatically and the "Retry live view" flow actually
  re-establishes frames.

## Gateway stability and pairing

- Reconnect uses bounded backoff and honest health reporting; the UI can no
  longer be stuck on "Reconnecting" without a working retry/debug action.
- Pairing challenge creation errors are fixed and QR pairing is supported on the
  PC Companion flow.
- Debug bundles capture the connection timeline, recent events and gateway logs.

## Codex MCP

- Codex can auto-detect the connected phone through the PC gateway, browse pages
  with context, capture screenshots, run typed actions and pull debug bundles.
- A new agent-facing guide documents the exact setup and tool call order.

## Verification status

This release is a beta. Physical-device status and CI artifact evidence are
recorded in `releases/<version>/BUILD_VERIFIED.json` once a build is verified.
Until that evidence exists, nothing in this document should be read as a verified
production claim.
