# Cyclone 3.6.0-beta.2

Sideload hotfix. Physical Pixel 8 is still **UNVERIFIED**.

## Downloads
- **Cyclone Mobile 3.6.0-beta.2** — Android APK (`versionCode` 42, package `com.cyclone.mobile`)
- **Teamwork Sniper 3.5.3.3** — separate Picnic Teamwork APK
- **Cyclone PC Companion 3.6.0-beta.2** — Windows installer

## Why the previous APK said “App not installed” on a clean Pixel
This was **not** an old Cyclone leftover. The 3.6.0-beta / beta.1 pipeline published `assembleDebug` APKs. Android marks those `android:testOnly="true"`. The system Package Installer rejects them with only “App not installed”, even when `com.cyclone.mobile` is absent.

## Fixes in this build
- CI now runs `:app:assembleRelease` and ships `app-release.apk`.
- The release APK is signed with the pinned debug keystore so later 3.6 betas can update in place.
- CI refuses to publish if `aapt dump badging` still reports `testOnly=true`.
- NSIS installer-hooks comments are valid again (`because` is no longer parsed as a command), so Combined Release CI can publish.

## Install this build
1. On the Pixel: Settings → Apps → search **Cyclone**. If anything is there, uninstall it. You said it is already gone — that is fine.
2. Enable Install unknown apps for Chrome / Files.
3. Download `Cyclone-3.6.0-beta.2.apk` from this release and open it.
4. Approve the install. The app name is **Cyclone**.

If Play Protect blocks it, tap More details → Install anyway. This APK is a CI-signed beta, not a Play Store build.

## What this is not
- Not 4.0.0 and not a stable `main` release.
- Pixel slices 1–4 remain **UNVERIFIED**.
- The Windows installer is still unsigned.
