# Cyclone 3.7.0-beta

First product step after 3.6.0: four-tool MCP skill loop, overlay chrome, GATE + Automations drafts. This is a **pre-release**. It is not 4.0.0. Physical Pixel 8 UI slices stay **UNVERIFIED**.

Merged onto `release/beta/cyclone-3.6.0`: PR #38 (MCP), PR #36 (overlay), PR #37 (GATE).

## Downloads
- **Cyclone-3.7.0-beta.apk** — Android phone app (`versionCode` 44, package `com.cyclone.mobile`)
- **Teamwork-Sniper-3.5.3.3.apk** — separate Picnic Teamwork app (unchanged)
- **Cyclone-PC-Companion-3.7.0-beta-Setup.exe** — Windows installer

## What this build changes
- MCP default surface: `phone_status` → `phone_locate(goal)` → `phone_act` → `phone_skill_save` | `phone_skill_run`
- One Compose overlay (`IDLE | ANALYSIS | WORKING | LIVE | GATE | DONE`). Overlay buttons never click host nodes. GATE ignores PC `autoApprove`.
- Overlay DONE and MCP `phone_skill_save` compile disabled drafts (`status=draft`, `enabled=false`) into the existing `AutomationStore`. Workers/PC cannot flip draft → verified.
- Signed with the same Cyclone-owned release key as 3.6.0. arm64-only. Not `testOnly`.

## Known limitations
- Physical Pixel acceptance: **NOT RUN**
- Live Android `skill.compile` / `skill.run` / `skill.match` gateway ops are still fail-closed until the phone protocol lands them. Draft compile on-device via `SkillCompiler` is in this APK; PC live save/run may return `UNKNOWN_OPERATION` / `CAPABILITY_UNAVAILABLE` until then.
- Food-order vertical is the 4.0.0 demo, not this sprint.

## Install on the Pixel
1. Uninstall any older Cyclone first if it was signed with a different key.
2. Download **Cyclone-3.7.0-beta.apk**. Wait until Files shows ~50–70 MB, not a 1 KB HTML file.
3. Open the APK → Install. If Play Protect warns: More details → Install anyway.

Do not tag or advertise 4.0.0.
