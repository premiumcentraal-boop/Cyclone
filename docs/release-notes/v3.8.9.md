# Cyclone 3.8.9

Cyclone 3.8.9 is a focused OpenRouter compatibility hotfix on top of the 3.8.7 mobile runtime.

## Fix

- Simplifies Cyclone's OpenRouter chat request to the bare routing-safe minimum: `model` + `messages`.
- Removes Cyclone-imposed `max_tokens`, temperature, reasoning parameters, JSON response mode, provider sorting, and `require_parameters`.
- Lets the selected model/provider use its own supported defaults instead of filtering every endpoint through an unnecessarily strict parameter set.
- Keeps the existing Android execution, GATE, verification, Brain and recovery behavior unchanged.

## Identity and verification

- Version: `3.8.9`
- Android versionCode: `53`
- Package: `com.cyclone.mobile`
- Automated Android unit tests and release assembly: required before publication
- APK checksum and exact source-SHA provenance: required before publication
- Physical Pixel 8 acceptance: `UNVERIFIED` in this environment

This release is intentionally narrow. The larger 3.8.8-style native tool-loop work remains separate and is not included in this hotfix.
