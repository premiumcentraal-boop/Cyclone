# Cyclone Mobile 3.8.8 — Agentic Tool Harness Test Release

Cyclone 3.8.8 replaces the released 3.8.7 page-decision reasoning path with a persistent native tool-calling agent loop:

`LLM → TOOL CALL → TOOL RESULT → LLM`

## Highlights

- Real OpenRouter/OpenAI-compatible native `tools` / `tool_calls` conversation semantics.
- Persistent same-task conversation across multiple tool calls and recoveries.
- `open_app(name)` resolves human app names locally, launches through the canonical Android executor, re-observes, and verifies the resulting package.
- High-bandwidth `understand_page(goal)` combines one authoritative Page Card with goal-ranked controls, Brain/App Graph hints, installed-app matches, previous verified action evidence, and screenshot eligibility.
- Batched `search(queries[])` and `inspect(elementIds[])` reduce unnecessary LLM round trips.
- `visual_context(goal)` provides screenshot metadata plus semantic page evidence without treating screenshots as proof of success.
- Mutating tools return Android execution, fresh after-state, semantic verification, typed failure, delta, and learning status in one result.
- Detailed tool failures are preserved into the next model turn instead of collapsing into generic error tokens.
- Model call count is telemetry rather than a normal six-turn cutoff.
- Unverified final answers are rejected back into the same model conversation.
- GATE suspends and resumes the same task; a fresh read is required after resume before another mutation.
- Blind multi-mutation batches are serialized by requiring the model to replan from fresh tool results.
- Repeated no-progress actions remain bounded by deterministic non-convergence safeguards.
- Brain now includes a Runs surface with run detail, metrics, tool timeline, verification, recovery, and learning evidence.
- Completed/failed runs can export a sanitized diagnostic ZIP containing `run.json`, `timeline.txt`, and `metadata.json`.
- Diagnostic logs redact credentials, OTP/PIN/password/API-key values, typed plaintext, private model reasoning, and screenshot binary/Base64 data.
- Short personality-driven activity messages show user-visible states such as “Reading the page 👀”, “Thinking…”, “Opening Chrome ⚡”, and “Checking it worked ✓”.

## Safety retained

Cyclone/Android remain authoritative for GATE, policy, credentials/OTP handling, observation-scoped IDs, Android execution, fresh after-state verification, convergence, and verified-only learning. The model may choose tools and strategy; it cannot declare Android actions successful by itself.
