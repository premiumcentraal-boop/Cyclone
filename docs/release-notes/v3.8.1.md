# Cyclone 3.8.1

Cyclone 3.8.1 is a coordinated Android and Windows release built from one source revision. It fixes the connected-agent path discovered during the Pixel 8 acceptance run while keeping Android policy and after-state verification authoritative.

## Downloads

- **Cyclone-3.8.1.apk** — Android app (`versionCode` 46, package `com.cyclone.mobile`)
- **Cyclone-PC-Companion-3.8.1-Setup.exe** — Windows Companion with the Device Gateway and canonical phone MCP
- Checksums, source SHA, build provenance, and third-party notices are attached to this release

## Fixed in 3.8.1

- The packaged Companion now serves the canonical phone tool surface, including `phone_locate`, `phone_skill_save`, and `phone_skill_run`, while retaining its connector and diagnostics commands.
- Compact locate and action responses keep bounded `pageText` and `pageSummary` evidence without leaking full raw Accessibility trees.
- Page-changing actions wait briefly for the actual Android transition and return a fresh after-state. Android marks success only when the expected app or a changed semantic state is observed.
- Unlabelled actionable Android containers inherit a safe visible descendant label, fixing rows such as Settings → Apps without coordinate or screenshot fallback.
- Cyclone's **Phone task** field now exposes an explicit editable Accessibility label for typed connected-agent tasks.
- Observation-scoped element IDs still expire after mutation; stale IDs fail closed.
- Skill compilation remains draft-only and disabled. A draft cannot run live, and the PC cannot promote it to verified.

## Safety and verification

- Pay, send, delete, and permission-grant gates remain phone-side and cannot be bypassed by PC auto-approval.
- No arbitrary shell, ADB, root, or script tool is exposed to the model.
- The release metadata remains `physical_pixel8 = UNVERIFIED` until T0–T4 pass on the exact 3.8.1 release candidate. Any uncompleted shop, messaging, or human-approved skill checks remain honest skips rather than implied passes.

## Installation

Install the Windows Companion, then install the matching APK on the Pixel. If Android reports a signing conflict with an older build, removing that older app also removes its local Cyclone data, so export anything needed first.
