# Cyclone 3.8.0-beta

PC AI can save a draft skill and run a verified one on the phone, and `phone_locate(goal)` finds the labelled control on golden page fixtures. This is a **pre-release**. It is not 4.0.0. Physical Pixel 8 stays **UNVERIFIED**.

Merged onto `release/beta/cyclone-3.6.0`: PR #41 (Android skill ops), PR #40 (MCP live save/run), PR #39 (golden locate).

## Downloads
- **Cyclone-3.8.0-beta.apk** — Android phone app (`versionCode` 45, package `com.cyclone.mobile`)
- **Teamwork-Sniper-3.5.3.3.apk** — separate Picnic Teamwork app (unchanged)
- **Cyclone-PC-Companion-3.8.0-beta-Setup.exe** — Windows installer

## What this build changes
- Android gateway ops `skill.compile` / `skill.run` / `skill.match`. Compile always writes `status=draft`, `enabled=false`. PC cannot request verified. GATE pay/send/delete/grant stays phone-side; PC `autoApprove` is ignored.
- MCP live `phone_skill_save` / `phone_skill_run` through those ops. Unverified steps deny locally. Drafts need `dryRun=true`. Missing Android ops fail closed (`ANDROID_SKILL_OPS_MISSING`).
- `phone_locate(goal)` can match a verified skill (`skipModel=true`) and still always returns the Page Card.
- V4 slice 5: 12 **synthetic** golden locate fixtures. Labelled control must rank in the top hits. Silent drop of `pageText` / `pageSummary` is `AGENT_CONTEXT_TRUNCATION`. Not Pixel dumps.
- Signed with the same Cyclone-owned release key as 3.6.0 / 3.7.0-beta. arm64-only. Not `testOnly`.

## Known limitations
- Physical Pixel acceptance: **NOT RUN**
- Verified is a description marker only (`SkillCapsule` type is still DRAFT/QUARANTINED). No PC promotion path.
- Golden fixtures are synthetic, not device captures.
- Live PC skill save/run still needs the phone protocol hook on a physical device.

## Install on the Pixel
1. Uninstall any older Cyclone first if it was signed with a different key.
2. Download **Cyclone-3.8.0-beta.apk**. Wait until Files shows ~50–70 MB, not a 1 KB HTML file.
3. Open the APK → Install. If Play Protect warns: More details → Install anyway.

Do not tag or advertise 4.0.0.
