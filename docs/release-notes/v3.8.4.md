## Fixes in this candidate

- **TalkBack host folding** — Snapshot time folds labeled leaves into clickable parents (`ACTION_CLICK` / `isClickable`). Hosts publish `clickable=true` and role `row` / `button` / `tab` / `textbox`.
- **Tab role** — `inferRole` emits `tab` for TabLayout / TabWidget / selected tab patterns (Clock).
- **Host-first observation** — `bestNode` prefers the clickable host over a TextView child so cards do not show `clickable=false`.
- **WebView windows** — A focused Chrome/WebView window is included in the same snapshot when the preferred foreground root would hide it.
- **pageKey tabs** — Selected tab, pane title, and first heading are mixed into `pageKey` so Clock Timer vs Alarm differ.
- **Empty selector hard error** — Pixel click rejects empty selectors. `elementId` / `ref` map to a real selector. Never click the shallowest node as a fallback.
- **Page Card snapshot** — YAML-like `- role "Name" [ref=eN] [selected]` plus a ref map. Fresh snapshot after every mutate. Refs die on the next snapshot.
- **phone_act refs** — click/type/long_press accept `ref` or role+name, re-resolved against the current snapshot only. Stale ref → `STALE_OBSERVATION`. Auto observe/locate before the first mutate in a fresh session.
- **1-character ranker** — Goal `"7"` is a valid token. Keypad digits stay in the interactive snapshot (≤80 hosts) even when `current[12]` is full of editables.
- **Same-page verify** — Success if selected/checked/focused flipped, display/textbox value changed, or the goal label is present — not only `pageKey`/`pageChanged`. 1-character goals are allowed. Desktop does not wrap Android `OBSERVED` + execution ok into `VERIFICATION_FAILED`.
- **Compose type** — `ACTION_SET_TEXT` success is not `ASSERTION_FAILED` solely because `AccessibilityNodeInfo.text` does not mirror the typed value.
- **Files APK row click** — Generic Files hosts that only *look* named/clickable no longer steal the filename ref from the `ACTION_CLICK` button sibling. `phone.click` on the filename ref activates that button. Settings Network host click, Clock tabs, and Calculator digits stay on their own hosts.
- **Files row labels** — TalkBack fold concatenates descendant labels and prefers filename over date/size, so `Cyclone-*.apk` stays selectable.
- **Calculator keypad** — Interactive on-screen digits publish even when `visibleToUser=false`; 1-character labels stay unique (control key includes full path + node id). Sibling application windows are collected with the preferred root.
- **Clock/Files click** — `phone.click` matches TalkBack name (text or contentDescription), walks `ACTION_CLICK`/`ACTION_SELECT` hosts (not only `isClickable`), and resolves the live node from the same preferred window used to snapshot. Tab refs no longer ACTION_FAILED solely because the published node is a labeled child.
- **GATE move-to-bin** — Phrase matches `move to bin`, `move to trash`, `send to bin`, `send to trash`, `throw away`, and native `Move 1 file to bin`. Bare `bin`/`trash` stay ungated. `See all` stays ungated. `phone.click` classifies the target (and activation sibling) before ACTION_CLICK; a match enters overlay GATE from IDLE/WORKING/LIVE and does not perform the click.

Trust-session pairing crypto is unchanged. Typed plaintext is never echoed.
