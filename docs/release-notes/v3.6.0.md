# Cyclone 3.6.0

Full GitHub release (not a pre-release). Physical Pixel 8 UI slices are still **UNVERIFIED**.

## Downloads
- **Cyclone-3.6.0.apk** — Android phone app (`versionCode` 43, package `com.cyclone.mobile`)
- **Teamwork-Sniper-3.5.3.3.apk** — separate Picnic Teamwork app
- **Cyclone-PC-Companion-3.6.0-Setup.exe** — Windows installer

## Why earlier 3.6 APKs said “App not installed”
The word “beta” is **not** an Android install flag. These were the real blockers:
1. `3.6.0-beta` shipped `assembleDebug` (`android:testOnly=true`). The system installer rejects that even on a clean phone.
2. `3.6.0-beta.2` was a real release APK (~100 MB) still signed with the public Android debug certificate, and it packaged extra CPU libraries. A partial Chrome download of a 100 MB APK also installs as “App not installed”.

## What this build changes
- Version name is `3.6.0` so GitHub publishes it as a full release, not a pre-release.
- Signed with a Cyclone-owned release key, not `androiddebugkey`.
- Pixel 8 APK contains only `arm64-v8a` native code, so the file is smaller and Android 15 does not see the 4KB-aligned 32-bit WebRTC libs.
- Still not `testOnly`.

## Install on the Pixel
1. Settings → Apps → see all apps → search **Cyclone**. If it exists (including Disabled / Private Space), uninstall it. A leftover 3.5.x signed with a different key still blocks this package.
2. On the phone, download **Cyclone-3.6.0.apk** from this release. Wait until Files shows ~50–70 MB, not a 1 KB HTML file.
3. Open the APK → Install. If Play Protect warns: More details → Install anyway.

Do not use `Cyclone-3.6.0-beta.apk` or `Cyclone-3.6.0-beta.2.apk`.
