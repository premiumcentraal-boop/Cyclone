# Cyclone 3.8.6

Cyclone 3.8.6 is a focused OpenRouter model and overlay settings update.

## What changed

- The built-in model list is now Gemini 3.8 Flash, GPT-5.6 Luna, GLM 5.3 Flash, Muse Spark 1.3, and GPT-5.6 Sol.
- The aurora overlay has a compact settings button for fast model switching.
- The same panel exposes a four-position intelligence slider: Low, Medium, High, and Max.
- Model and intelligence choices persist and apply to the next AI request.

## Identity and verification

- Version: `3.8.6`
- Android versionCode: `51`
- Package: `com.cyclone.mobile`
- Physical phone acceptance: not run; this build is intended for user testing.
