# Archive

Plans, sprint checkpoints, handoffs and operator notes from earlier Cyclone versions (3.x, 4.x, V4, Cyclone One 1.x and
early V5 release lanes). They are kept for history. They do not describe the current product, and the lanes and scripts
some of them name no longer exist. For how Cyclone works today, start at [`../README.md`](../README.md).
